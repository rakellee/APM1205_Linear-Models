# APM1205: Formative Assessment 4 – Dummy-Variable Regression

**Course:** APM1205 - Applied Regression Analysis
**Topic:** Dummy-Variable Regression Using Real-World Data  
**Dataset:** `ggplot2::diamonds`  

---

## Overview

This repository contains the complete reproducible code, visualization outputs, and formal assessment report for **Formative Assessment 4 (FA4)**. The objective is to examine the relationship between diamond weight (`carat`), cut quality (`cut`), and diamond valuation (`price`) using ordinary least squares (OLS) dummy-variable regression and incremental $F$-tests.
